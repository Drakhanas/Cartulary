# Release notes

What each Cartulary release shipped, kept verbatim. The `Cartulary_v<version>_PatchNotes.txt` files are the patch notes, one per version from v1.4 on. Each `v<version>/` folder holds the text that release's zip carried, under its original file names; `v1.6/` also holds the itch page, the devlog, and the finals checklist. The application files aren't here: v1.6's are rebuilt byte for byte from the `v1.6` tag, and the earlier ones predate the repository.

The hashes are of the files in Drak's archive of every release, read on 2026-10-23. Nothing recorded the earlier releases' hashes when they shipped. Where a ship record exists, the archive agrees with it: v1.4's three HTML files have the byte counts `changelog-v1.4.md` gives, v1.5's match the sizes `changelog-v1.5.md` gives for the r134 finals (2.50 MB and 5.77 MB), and v1.6's are the hashes in the handoff, which a clean checkout of the `v1.6` tag rebuilds.

Notes on the originals, which are left as they shipped:

- v1.4's patch notes shipped as `Cartulary_v1.4_patchnotes.txt` and are renamed here to match the others; the content is unchanged. The v1.4 zip also held the working copy (`Cartulary_v1.4_WorkingFinal.html`, `6b45b54bee1538f9`) and a sample world, which the list of contents in its patch notes doesn't mention.
- v1.5's zip held no README: only the two builds and the patch notes.
- The dates disagree. `v1.3/CHANGELOG.md` puts v1.0 in March 2026 and v1.1 in April, and the frozen `changelog-v1.1-v1.3.md` puts v1.1 in late April, but the files in the v1.0 and v1.1 zips are dated May 3 to 7.
- The early READMEs name files the zips don't hold under those names: v1.0's says `cartulary.html` for `Cartulary.html`, and v1.1's says `cartulary.html` and `cartulary-readable.html` for `Cartulary_v1.1.html` and `Cartulary_v1.1_Readable.html`.
